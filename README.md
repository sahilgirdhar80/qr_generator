# 🚀 QR Code Generator 📷

A **simple and efficient** QR Code Generator built with **Node.js**. Convert any URL into a **scannable QR code** within seconds! 🎯

## ✨ Features
✅ Generate a QR Code from any URL 🔗  
✅ Save the QR Code as an image 🖼️  
✅ Lightweight and easy to use 🛠️  
✅ Uses **Node.js** and the `qrcode` package 🖥️
